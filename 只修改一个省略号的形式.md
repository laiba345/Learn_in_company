1. 任务层级展示：接收 tasks，将 Main Task 与 children 展开为两层列表并生成 1.、1.1 等显示编号。

   并通过 task-change 将 Main Task 和全部 Sub Task 分别标记为 delete。
4. 任务升级与降级：最多支持 Main Task -> Sub Task 两层。第一条或已有 children 的 Main Task

任务移动规则:

   - 移动后由 visibleTasks 重新计算 Main Task 和 Sub Task 的显示编号。

2. Sub Task 上移/下移
   - 只能在当前 Main Task 的 children 范围内调整顺序。
   - 不能通过上移进入上一个 Main Task，也不能通过下移进入下一个 Main Task。

3. 新建任务
   - 新建 Main Task 和已保存的 Main Task 使用相同规则，可在 Main Task 层级自由移动。
   - 新建 Main Task 降级后成为 Sub Task，只能在所属 Main Task 内移动。
   - 不根据任务是否已保存设置特殊移动权限。

4. Sub Task 跨组
   - Sub Task 如需移动到其他 Main Task，必须先升级为 Main Task。

任务操作与变更上报规则:
1. 新增任务
   - 新任务通过 task-change 标记为 create。
   - 新任务继续编辑、移动、升级或降级时仍保持 create，不转为 update。
   - 新增导致其他已有任务 sort_no 变化时，受影响的已有任务标记为 update。

2. 编辑任务
   - 修改任务名称、Progress、可编辑日期，或为新建/未分配 Owner 的任务选择 Owner 时，只上报当前操作的任务。
   - 已有任务标记为 update；没有执行编辑动作的任务不需要上报。

3. 删除任务
   - 已有任务标记为 delete，父组件按任务 ID 移除其之前的 update 状态。
   - 新任务删除时只撤销 create，不调用后台删除接口。
   - 删除 Main Task 时，Main Task 和其全部 Sub Task 都必须分别标记为 delete。
   - 删除导致其他任务 sort_no 变化时，受影响的任务也需要上报。

4. 上下移动
   - 移动完成后重新生成当前任务树的 sort_no。
   - 所有 sort_no 发生变化的 Main Task 和 Sub Task 都需要上报。
   - 已有任务标记为 update，新任务仍保持 create。

5. 升级与降级
   - Sub Task 升级为 Main Task、Main Task 降级为 Sub Task 后重新生成 sort_no。
   - 被操作任务及其他 sort_no 发生变化的任务都需要上报。
   - 升级或降级只改变任务层级和顺序，不修改任务内容。

6. 状态覆盖
   - 同一个任务在父组件中最终只保留 create、update、delete 中的一种状态。
   - delete 覆盖 update；create 不会因为后续编辑或结构操作变成 update。

关键业务规则:
- Main Task 在顶层 tasks 数组中移动，并保留完整 children。
- Sub Task 只在所属 Main Task 的 children 数组中移动。
- 移动操作只改变任务顺序，不修改任务内容和父子层级。
- 组件先复制任务数据再调整结构，不直接修改 props，也不修改后端任务字段名。

- 日期汇总不读取 status；Sub Task 日期或任务层级变化后，通过 tasks-change 传递重新汇总的任务树。
- 最后一条 Main Task 不允许删除，避免列表清空后失去新增 Main Task 的操作入口。
- 前端新建的 Main/Sub Task 使用 isNew 标记；升级、降级和移动时保留该标记，供后续接口分流。

import ProjectDatePicker from '@project_sensing/components/common/ProjectDatePicker.vue';
import ProjectInput from '@project_sensing/components/common/ProjectInput.vue';
import ProjectSelect from '@project_sensing/components/common/ProjectSelect.vue';

import moment from 'moment';

export default {
  name: 'TaskList',

  components: {
    ProjectDatePicker,
    ProjectInput,
    ProjectSelect,
  },

  props: {
    loading: {
      type: Boolean,
      default: false,
    },
    height: {
      type: Number,
      default: 0,
    },
    tasks: {
      type: Array,
      default: () => [],
    },

    members: {
      type: Array,
      default: () => [],
    },

    currentUser: {
      type: Object,
      default: () => ({}),
    },

    canManageTasks: {
      type: Boolean,
      default: false,
    },

    editMode: {
      type: Boolean,
      default: false,
    },

    projectClosed: {
      type: Boolean,
      default: false,
    },
  },

  data () {
    return {
      expandedTaskIds: [],
      editingTaskId: null,
      operationMode: '',
      dateFields: [
        { value: 'plan_start_date', text: 'Plan Start' },
        { value: 'plan_end_date', text: 'Plan End' },
        { value: 'commit_start_date', text: 'Commit Start' },
        { value: 'commit_end_date', text: 'Commit End' },
        { value: 'actual_start_date', text: 'Actual Start' },
        { value: 'actual_end_date', text: 'Actual End' },
      ],
    };
  },

  computed: {
    // 加载期间只隐藏内容行，表头保持渲染。
    renderedTasks () {
      return this.loading ? [] : this.visibleTasks;
    },
    tableHeaders () {
      const headers = [
        { value: 'task_name', text: 'Task Name' },
        { value: 'owner_name', text: 'Owner' },
        { value: 'status', text: 'Status' },
        { value: 'progress_pct', text: 'Progress' },
        ...this.dateFields,
      ];
      return this.editMode ? [...headers, { value: 'action', text: 'Action' }] : headers;
    },
    // 将 Main/Sub 两层任务树展开为表格行，并补充层级、父任务和显示编号。
    visibleTasks () {
      const result = [];

      this.tasks.forEach((mainTask, mainIndex) => {
        result.push({
          ...mainTask,
          level: 0,
          parentId: null,
          displayNo: mainTask.sort_no || `${mainIndex + 1}.`,
        });

        if (!this.isExpanded(mainTask.id)) {
          return;
        }

        (mainTask.children || []).forEach((subTask, subIndex) => {
          result.push({
            ...subTask,
            level: 1,
            parentId: mainTask.id,
            displayNo: subTask.sort_no || `${mainIndex + 1}.${subIndex + 1}`,
          });
        });
      });

      return result;
    },
  },

  watch: {
    // 进入编辑时初始化编辑状态；空任务列表自动创建一条可填写的 Main Task。
    editMode (editing) {
      if (!editing) {
        this.editingTaskId = null;
        this.operationMode = '';
        return;
      }

      const tasks = this.cloneTasks();
      let newTask = null;
      if (!tasks.length) {
        newTask = this.createEmptyMainTask(`main-${Date.now()}`);
        tasks.push(newTask);
        this.editingTaskId = newTask.id;
        this.operationMode = 'create';
      }
      this.emitTasks(tasks);
      if (newTask) {
        this.emitTaskChange(newTask, 'create');
      }
    },

    // 首次拿到任务时默认展开全部 Main Task。
    tasks: {
      immediate: true,
      handler (tasks) {
        if (!this.expandedTaskIds.length) {
          this.expandedTaskIds = tasks.map(task => task.id);
        }
      },
    },

    // 展开状态或任务内容变化时，将当前可见行同步给 Timeline。
    visibleTasks: {
      immediate: true,
      handler (tasks) {
        this.$emit('visible-change', tasks);
      },
    },
  },

  methods: {
    // 深拷贝 props 任务树，所有编辑动作都基于副本处理，避免直接修改父组件数据。
    cloneTasks () {
      return JSON.parse(JSON.stringify(this.tasks));
    },

    // 根据行层级和 ID 在任务树中找到对应的 Main Task 或 Sub Task。
    findTask (tasks, task) {
      if (task.level === 0) {
        return tasks.find(item => item.id === task.id);
      }

      const parent = tasks.find(item => item.id === task.parentId);
      return parent && (parent.children || []).find(item => item.id === task.id);
    },

    // 将 Main Task 和直属 Sub Task 展平，统一检查 ID 与 sort_no。
    flattenTasks (tasks) {
      return tasks.reduce((result, mainTask) => (
        result.concat(mainTask, mainTask.children || [])
      ), []);
    },

    // 保存结构操作前的 sort_no，用于定位真正受排序影响的任务。
    getTaskSortNoMap (tasks) {
      return new Map(this.flattenTasks(tasks).map(task => [
        String(task.id),
        task.sort_no,
      ]));
    },

    // 只上报 sort_no 发生变化的任务；新任务通过 isNew 继续保持 create。
    emitSortNoChanges (tasks, beforeSortNoMap) {
      this.flattenTasks(tasks).forEach(task => {
        const taskId = String(task.id);
        if (beforeSortNoMap.has(taskId)
          && beforeSortNoMap.get(taskId) !== task.sort_no) {
          this.emitTaskChange(task, 'update');
        }
      });
    },

    // 后台删除 Main Task 时要求同时传入该 Main Task 下全部 Sub Task 的 ID。
    getDeletedTasks (task) {
      return task.level === 0
        ? [task, ...(task.children || [])]
        : [task];
    },

    // 删除覆盖已有状态；新增任务后续编辑仍保持 create。
    getTaskActionStatus (task, type) {
      if (type === 'delete') return 'delete';
      if (type === 'create' || task.isNew || task.actionStatus === 'create') return 'create';
      return 'update';
    },

    // 只发送本次新增、修改或删除的 Task；新任务继续编辑时仍保持 create。
    emitTaskChange (task, type) {
      task.actionStatus = this.getTaskActionStatus(task, type);
      this.$emit('task-change', {
        type: task.actionStatus,
        task: JSON.parse(JSON.stringify(task)),
      });
    },

    // 统一整理层级编号和 Main Task 汇总日期，再将完整任务树传给父组件。
    emitTasks (tasks) {
      const normalizedTasks = this.normalizeTaskMeta(tasks);
      const nextTasks = this.aggregateMainTaskDates(normalizedTasks);
      this.$emit('tasks-change', nextTasks);
      return nextTasks;
    },

    // 按当前父子顺序重新生成 task_type 和后端展示编号 sort_no。
    normalizeTaskMeta (tasks) {
      return tasks.map((mainTask, mainIndex) => {
        mainTask.task_type = 'Master';
        mainTask.sort_no = `${mainIndex + 1}.`;
        (mainTask.children || []).forEach((subTask, subIndex) => {
          subTask.task_type = 'Sub';
          subTask.sort_no = `${mainIndex + 1}.${subIndex + 1}`;
        });
        return mainTask;
      });
    },

    // 有 Sub Task 时，使用子任务最早 Start、最晚 End 汇总 Main Task 日期。
    aggregateMainTaskDates (tasks) {
      return tasks.map(mainTask => {
        const children = Array.isArray(mainTask.children)
          ? mainTask.children
          : [];

        if (!children.length) {
          return mainTask;
        }

        const aggregateDate = (field, mode) => {
          const dates = children
            .map(child => child[field])
            .filter(date => moment(date, 'YYYY-MM-DD', true).isValid());

          if (!dates.length) {
            return '';
          }

          return dates.sort()[mode === 'min' ? 0 : dates.length - 1];
        };

        mainTask.plan_start_date = aggregateDate('plan_start_date', 'min');
        mainTask.plan_end_date = aggregateDate('plan_end_date', 'max');
        mainTask.commit_start_date = aggregateDate('commit_start_date', 'min');
        mainTask.commit_end_date = aggregateDate('commit_end_date', 'max');
        mainTask.actual_start_date = aggregateDate('actual_start_date', 'min');
        // 不依赖后台状态；只有每个 Sub Task 都填写 Actual End，Main Task 才产生 Actual End。
        mainTask.actual_end_date = children.every(child => (
          moment(child.actual_end_date, 'YYYY-MM-DD', true).isValid()
        ))
          ? aggregateDate('actual_end_date', 'max')
          : '';

        return mainTask;
      });
    },

    // 更新任务普通字段，并通过统一出口重新汇总和上报任务树。
    updateField (task, field, value) {
      if (!this.canUpdateField(task, field)) return;
      const tasks = this.cloneTasks();
      const target = this.findTask(tasks, task);

      if (!target) {
        return;
      }

      target[field] = value;
      this.emitTasks(tasks);
      this.emitTaskChange(target, 'update');
    },

    // 根据下拉选择同时写入保存需要的 owner_id 和 owner_name。
    updateOwner (task, ownerId) {
      if (!this.canEditOwner(task)) return;
      const member = this.members.find(item => item.owner_id === ownerId);
      const tasks = this.cloneTasks();
      const target = this.findTask(tasks, task);

      if (!target) {
        return;
      }

      target.owner_id = ownerId;
      target.owner_name = member ? member.owner_name : '';
      this.emitTasks(tasks);
      this.emitTaskChange(target, 'update');
    },

    // 将进度转换为 0 至 100 的数字后更新 progress_pct。
    updateProgress (task, value) {
      const progress = Math.min(100, Math.max(0, Number(value) || 0));
      this.updateField(task, 'progress_pct', progress);
    },

    // 新任务直接编辑；已有任务只有点击铅笔后才进入行编辑状态。
    isTaskEditing (task) {
      return this.editMode
        && !this.projectClosed
        && (task.isNew || this.editingTaskId === task.id);
    },

    // Commit 任一日期已填写后锁定 Owner，避免变更负责人后造成已承诺日期的责任归属不一致。
    canEditOwner (task) {
      return this.isTaskEditing(task)
        && this.canManageTasks
        && !String(task.commit_start_date || '').trim()
        && !String(task.commit_end_date || '').trim();
    },

    // 判断任务是否为带后台 ID 的已保存数据。
    hasBackendId (task) {
      return !task.isNew
        && task.id !== undefined
        && task.id !== null
        && task.id !== '';
    },

    // 新增期间禁止进入已有任务的编辑模式，避免新增和编辑混合保存。
    canEditTask (task) {
      return this.operationMode !== 'create'
        && this.hasBackendId(task)
        && (this.canManageTasks || this.isTaskOwner(task));
    },

    // 新增期间只允许操作新任务，已有任务的结构操作保持禁用。
    canOperateTask (task) {
      return this.operationMode !== 'create' || task.isNew;
    },

    // 将已有任务切换为 update 模式并打开该行输入控件。
    editTask (task) {
      if (!this.canEditTask(task)) {
        return;
      }

      this.operationMode = 'update';
      this.editingTaskId = task.id;
    },
    hasCompletePlanDates (task) {
      return Boolean(String(task.plan_start_date || '').trim())
        && Boolean(String(task.plan_end_date || '').trim());
    },
    hasCompleteCommitDates (task) {
      return Boolean(String(task.commit_start_date || '').trim())
        && Boolean(String(task.commit_end_date || '').trim());
    },
    // 有 children 的 Main Task 日期来自汇总； Commit Start 依赖 Plan Start，Commit End 依赖 Plan End；Commit 时间还必须由当前 Task Owner 填写。
    canEditDate (task, field) {
      const hasChildren = task.level === 0
        && Array.isArray(task.children)
        && task.children.length > 0;
      if (!this.editMode || this.projectClosed || hasChildren) return false;
      if (['commit_start_date', 'commit_end_date'].includes(field)) {
        return this.isTaskOwner(task) && this.hasCompletePlanDates(task);
      }
      if (['actual_start_date', 'actual_end_date'].includes(field)) {
        return this.canManageTasks && this.hasCompleteCommitDates(task);
      }
      return this.canManageTasks;
    },

    // 工号统一转成大写后比较；Admin/PM 非 Owner 时也不能填写 Commit 时间。
    isTaskOwner (task) {
      const currentUserId = String(this.currentUser.id || '').trim().toUpperCase();
      return Boolean(currentUserId)
        && String(task.owner_id || '').trim().toUpperCase() === currentUserId;
    },

    // 方法内部再次限制字段，避免绕过输入控件的 disabled 或 v-if 直接修改任务副本。
    canUpdateField (task, field) {
      if (['commit_start_date', 'commit_end_date'].includes(field)) {
        return this.isTaskOwner(task) && this.hasCompletePlanDates(task);
      }
      if (['actual_start_date', 'actual_end_date'].includes(field)) {
        return this.canManageTasks && this.hasCompleteCommitDates(task);
      }
      return this.canManageTasks;
    },
    // End 日期选择器最小值取同组 Start，确保 Start 不晚于 End。
    getDateMin (task, field) {
      const startFieldMap = {
        plan_end_date: 'plan_start_date',
        commit_end_date: 'commit_start_date',
        actual_end_date: 'actual_start_date',
      };
      return task[startFieldMap[field]] || '';
    },

    // Start 日期选择器最大值取同组 End，确保 Start 不晚于 End。
    getDateMax (task, field) {
      const endFieldMap = {
        plan_start_date: 'plan_end_date',
        commit_start_date: 'commit_end_date',
        actual_start_date: 'actual_end_date',
      };
      return task[endFieldMap[field]] || '';
    },

    // 在当前 Main Task 后插入一条空 Main Task，并切换为 create 模式。
    addMainTask (task) {
      if (this.operationMode === 'update') {
        return;
      }

      const tasks = this.cloneTasks();
      const beforeSortNoMap = this.getTaskSortNoMap(tasks);
      const index = tasks.findIndex(item => item.id === task.id);
      if (index === -1) {
        return;
      }

      const newTask = this.createEmptyMainTask(`main-${Date.now()}`);
      tasks.splice(index + 1, 0, newTask);
      this.operationMode = 'create';
      this.editingTaskId = newTask.id;
      const nextTasks = this.emitTasks(tasks);
      this.emitTaskChange(newTask, 'create');
      this.emitSortNoChanges(nextTasks, beforeSortNoMap);
    },

    // 在当前 Sub Task 后新增一条同级 Sub Task，并保持在原 Main Task 的 children 中。
    addSubTask (task) {
      if (this.operationMode === 'update' || task.level !== 1) {
        return;
      }

      const tasks = this.cloneTasks();
      const beforeSortNoMap = this.getTaskSortNoMap(tasks);
      const parent = tasks.find(item => item.id === task.parentId);
      const subTaskIndex = parent
        ? (parent.children || []).findIndex(item => item.id === task.id)
        : -1;
      if (!parent || subTaskIndex === -1) {
        return;
      }

      const newTask = this.createEmptySubTask(`sub-${Date.now()}`);
      parent.children.splice(subTaskIndex + 1, 0, newTask);
      this.operationMode = 'create';
      this.editingTaskId = newTask.id;
      const nextTasks = this.emitTasks(tasks);
      this.emitTaskChange(newTask, 'create');
      this.emitSortNoChanges(nextTasks, beforeSortNoMap);
    },

    // 复用空 Sub Task 字段创建 Main Task，并增加 children 数组。
    createEmptyMainTask (id) {
      return {
        ...this.createEmptySubTask(id),
        children: [],
      };
    },

    // 创建使用后端字段名的空任务，新任务通过 isNew 参与保存分流。
    createEmptySubTask (id) {
      return {
        id,
        isNew: true,
        task_type: 'Sub',
        sort_no: '',
        task_name: '',
        owner_id: '',
        owner_name: '',
        status: '',
        progress_pct: 0,
        plan_start_date: '',
        plan_end_date: '',
        commit_start_date: '',
        commit_end_date: '',
        actual_start_date: '',
        actual_end_date: '',
      };
    },

    // 后台为空时自动生成的第一条新 Main Task 使用 Reset，清空内容并撤销此前的 create 记录。
    resetTask (task) {
      if (!this.canManageTasks || !this.isResettableTask(task)) {
        return;
      }

      const resetTasks = this.getDeletedTasks(task);
      const emptyTask = this.createEmptyMainTask(task.id);
      this.editingTaskId = emptyTask.id;
      this.operationMode = 'create';
      this.expandedTaskIds = [emptyTask.id];
      this.emitTasks([emptyTask]);
      resetTasks.forEach(resetTask => this.emitTaskChange(resetTask, 'delete'));
    },
    // 删除指定任务；删除 Main Task 时一并移除其 children。
    deleteTask (task) {
      if (!this.canManageTasks || !this.canDeleteTask(task)) {
        return;
      }

      const tasks = this.cloneTasks();
      const beforeSortNoMap = this.getTaskSortNoMap(tasks);
      const deletedTasks = this.getDeletedTasks(task);
      const deletedTaskIds = new Set(deletedTasks.map(item => String(item.id)));

      // 删除当前编辑任务或其所属 Main Task 时，清除行编辑状态，避免其他新增按钮持续禁用。
      if (deletedTaskIds.has(String(this.editingTaskId))) {
        this.editingTaskId = null;
        this.operationMode = '';
      }
      // 展开状态只保留仍存在的 Main Task，避免删除后残留无效 ID。
      this.expandedTaskIds = this.expandedTaskIds.filter(id => (
        !deletedTaskIds.has(String(id))
      ));

      if (task.level === 0) {
        const nextTasks = tasks.filter(item => item.id !== task.id);
        this.resetCreateModeIfNeeded(nextTasks);
        const normalizedTasks = this.emitTasks(nextTasks);
        deletedTasks.forEach(deletedTask => this.emitTaskChange(deletedTask, 'delete'));
        this.emitSortNoChanges(normalizedTasks, beforeSortNoMap);
        return;
      }

      const parent = tasks.find(item => item.id === task.parentId);
      if (parent) {
        parent.children = (parent.children || []).filter(item => item.id !== task.id);
        this.resetCreateModeIfNeeded(tasks);
        const normalizedTasks = this.emitTasks(tasks);
        deletedTasks.forEach(deletedTask => this.emitTaskChange(deletedTask, 'delete'));
        this.emitSortNoChanges(normalizedTasks, beforeSortNoMap);
      }
    },

    // Sub Task 均可删除；Main Task 至少保留一条作为继续新增的入口。
    canDeleteTask (task) {
      return task.level === 1 || this.tasks.length > 1;
    },

    // 只有后台为空时自动生成的第一条新 Main Task 才显示 Reset；已有后台 ID 的任务保持 Delete。
    isResettableTask (task) {
      return task.level === 0
        && task.isNew
        && !this.hasBackendId(task)
        && this.tasks.length === 1;
    },
    // 当任务树已无 isNew 数据时退出 create 模式，恢复已有任务操作。
    resetCreateModeIfNeeded (tasks) {
      const hasNewTask = tasks.some(mainTask => (
        mainTask.isNew
        || (mainTask.children || []).some(subTask => subTask.isNew)
      ));

      if (this.operationMode === 'create' && !hasNewTask) {
        this.operationMode = '';
        this.editingTaskId = null;
      }
    },

    // 获取任务同层级数组，Main 使用顶层 tasks，Sub 使用所属 Main 的 children。
    getTaskSiblings (tasks, task) {
      if (task.level === 0) {
        return tasks;
      }

      const parent = tasks.find(item => item.id === task.parentId);
      return parent ? parent.children || [] : [];
    },

    // 判断目标方向是否仍在当前同级数组范围内。
    canMove (task, offset) {
      const siblings = this.getTaskSiblings(this.tasks, task);
      const index = siblings.findIndex(item => item.id === task.id);
      const targetIndex = index + offset;
      return index !== -1 && targetIndex >= 0 && targetIndex < siblings.length;
    },

    // 在同级数组中交换任务顺序，不改变 Main/Sub 层级关系。
    moveTask (task, offset) {
      if (!this.canOperateTask(task)) {
        return;
      }

      const tasks = this.cloneTasks();
      const beforeSortNoMap = this.getTaskSortNoMap(tasks);
      const siblings = this.getTaskSiblings(tasks, task);
      const index = siblings.findIndex(item => item.id === task.id);
      const targetIndex = index + offset;

      if (index === -1 || targetIndex < 0 || targetIndex >= siblings.length) {
        return;
      }

      // 上下移动只调整当前层级内的顺序，不改变 Main Task 与 Sub Task 的归属关系。
      const movedTask = siblings.splice(index, 1)[0];
      siblings.splice(targetIndex, 0, movedTask);
      const nextTasks = this.emitTasks(tasks);
      this.emitSortNoChanges(nextTasks, beforeSortNoMap);
    },

    // 只有 Sub Task 可以升级为 Main Task。
    canPromote (task) {
      return task.level === 1;
    },

    // 将 Sub Task 从原 children 移出，并插入原 Main Task 的下一行。
    promoteTask (task) {
      if (!this.canOperateTask(task)) {
        return;
      }

      const tasks = this.cloneTasks();
      const beforeSortNoMap = this.getTaskSortNoMap(tasks);
      const parentIndex = tasks.findIndex(item => item.id === task.parentId);

      if (parentIndex === -1) {
        return;
      }

      const children = tasks[parentIndex].children || [];
      const childIndex = children.findIndex(item => item.id === task.id);

      if (childIndex === -1) {
        return;
      }

      // 升级只改变层级，任务字段原样保留。
      const promotedTask = children.splice(childIndex, 1)[0];
      promotedTask.children = [];
      tasks.splice(parentIndex + 1, 0, promotedTask);
      const nextTasks = this.emitTasks(tasks);
      this.emitSortNoChanges(nextTasks, beforeSortNoMap);
    },

    // 非第一条且没有 children 的 Main Task 才能降级。
    canDemote (task) {
      if (task.level !== 0 || (task.children || []).length) {
        return false;
      }

      return this.tasks.findIndex(item => item.id === task.id) > 0;
    },

    // 将 Main Task 降级并追加到前一个 Main Task 的 children 末尾。
    demoteTask (task) {
      if (!this.canOperateTask(task)) {
        return;
      }

      const tasks = this.cloneTasks();
      const beforeSortNoMap = this.getTaskSortNoMap(tasks);
      const taskIndex = tasks.findIndex(item => item.id === task.id);

      if (taskIndex <= 0 || (tasks[taskIndex].children || []).length) {
        return;
      }

      const parent = tasks[taskIndex - 1];
      const demotedTask = tasks.splice(taskIndex, 1)[0];

      if (!Array.isArray(parent.children)) {
        this.$set(parent, 'children', []);
      }

      // 降级任务归入前一个 Main Task，并放在其现有 Sub Task 的最后。
      delete demotedTask.children;
      parent.children.push(demotedTask);

      if (!this.isExpanded(parent.id)) {
        this.expandedTaskIds.push(parent.id);
      }

      const nextTasks = this.emitTasks(tasks);
      this.emitSortNoChanges(nextTasks, beforeSortNoMap);
    },

    // 判断 Main Task 当前是否处于展开状态。
    isExpanded (id) {
      return this.expandedTaskIds.includes(id);
    },

    // 切换 Main Task 展开状态，仅影响可见行，不修改任务树。
    toggleTask (task) {
      const index = this.expandedTaskIds.indexOf(task.id);
      if (index === -1) {
        this.expandedTaskIds.push(task.id);
        return;
      }
      this.expandedTaskIds.splice(index, 1);
    },

    // 将空值或非法进度显示为 0，同时保留正常数字。
    normalizeProgress (progress) {
      return Number(progress) || 0;
    },

    // 获取任务状态对应的统一颜色配置。
    getStatusConfig (status) {
      return getProjectStatusConfig(status);
    },

    // 浏览模式将完整日期格式化为 MM-DD，空日期显示短横线。
    formatDate (date) {
      return date ? moment(date).format('MM-DD') : '-';
    },
    formatOwnerName (ownerName) {
      const name = String(ownerName || '').trim();
      if (!name) return '-';
      // 中文、数字或其他非纯英文姓名格式，保持完整显示。
      if (!/^[A-Za-z\s'-]+$/.test(name)) return name;
      const nameParts = name.split(/\s+/).filter(Boolean);
      // 英文名超过两个单词时，表格只展示前两个单词并明确标记省略。
      return nameParts.length > 2
        ? `${nameParts.slice(0, 2).join(' ')}...`
        : name;
    },
    hasTruncatedOwnerName (ownerName) {
      const name = String(ownerName || '').trim();
      if (!/^[A-Za-z\s'-]+$/.test(name)) return false;
      return name.split(/\s+/).filter(Boolean).length > 2;
    },
  },
};
</script>
